# My CFO

Static copy of the household ledger for GitHub Pages. The copy on your computer is separate and stays at http://localhost:5173/.

The shared numbers live in a private GitHub gist, not in this repository. Open the site, paste a GitHub token that can create gists, then choose the password. Copy the share link for anyone else. They still enter the password.

Build from the private project with `npm run build:pages`. Publish the `dist-pages` folder as this site.
